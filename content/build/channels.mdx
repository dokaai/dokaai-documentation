## Channels and providers

A channel is a delivery medium. Dokaai's handler configuration includes Email, SMS, Push, WhatsApp and In App channel types.

A provider integration is a configured connection to a delivery service. The handler's channel configuration selects from the provider integrations available to it. Channel type, provider account configuration and template content are separate concerns.

### What each channel means

| Channel | Customer experience |
| --- | --- |
| Email | A message delivered to an email address |
| SMS | A text message sent to a phone destination |
| Push | A notification delivered through the configured push provider/destination |
| WhatsApp | A WhatsApp message using the configured provider and template requirements |
| In App | A notification entry shown inside your application's customer experience |

For example, Email is the channel, a connected email vendor is the provider integration, and the order-confirmation subject/content is the template. Changing the template does not change the provider credentials. An [in-app inbox](/developers/in-app) also needs the application to fetch/display the customer's notifications.

### Where each choice belongs

| Choice | Where to work |
| --- | --- |
| Discover a provider and configure credentials | Existing [Integration directory](/integration) and provider guide |
| Enable a channel for a handler and select its integration | [Configure channels](/build/channels) |
| Author channel content and publish it | [Create and publish templates](/build/templates) |
| Select channels for a send | [Test and send notifications](/build/test-and-send) |

The Integration directory is the place to check available providers. A channel type does not imply that every provider or account is available for it. Follow the provider's requirements for recipient addresses, credentials and template use.

After connecting a provider, return to [handler channel configuration](/build/channels).

Before configuring channels, create a [notification handler](/build/handlers) and configure the provider integration needed for the channel. Provider discovery, credentials and provider-specific setup stay in the existing [Integration directory](/integration).

## Configure the handler channel

1. Open the handler's channel configuration.
2. Add or configure the channel you want to use.
3. Select from its available provider integrations and review the active state.
4. Save the configuration and check that the intended integration is associated with the channel.

The dashboard supports channel configuration for Email, SMS, Push, WhatsApp and In App. Availability of a particular provider depends on the Integration directory and the account configuration.

## Disable or restore a channel

Use the channel's available **Disable** or **Restore** action when adjusting its active state. Check the resulting configuration before sending. A disabled channel and an unpublished template are separate conditions.

Continue with [Create and publish templates](/build/templates) for each channel you intend to use. If an expected integration is missing, check the selected organization and provider setup before changing handler data.

The existing [Manage Channel Configuration](/api-reference/notification-handlers/manage-channel-configuration) operation owns the API contract.
