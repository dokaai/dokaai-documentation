Import customers into a selected [pool](/customers/pools) from a CSV file. Review the destination pool and, if applicable, target list before uploading.

## Prepare the CSV

Use the dashboard's template or upload controls for the pool. The file must use the `.csv` extension and include a `uniqueCustomerId` header. Column names must be non-empty and unique after normalization. Remove the template's example row and replace it with real customer records.

Keep customer identifiers consistent with the records you intend to maintain. Review contact values and custom-field types before submitting a large file.

## Upload and review

1. Open the customer import flow for the destination pool.
2. Upload the CSV and correct any header or example-row errors.
3. Review the field mappings. Match existing attributes deliberately and resolve any new custom-attribute validation errors.
4. Submit the import and retain the job information returned by the flow.
5. Inspect the background job in **Job Status**, then check representative customer records in the destination pool.

Uploading the file and creating an import job are separate from completion of that job. [Background jobs](/operations/jobs) explains the background-job view.

If validation or processing fails, use [Audience and import diagnostics](/troubleshooting/audiences). Avoid resubmitting a large file until you have checked the previous job's outcome.
