title: Apple Push Notification service integration guide
---

## Before you begin

- You need access to a Dokaai organization that can manage notification providers.
- Prepare an Apple Developer account, an application with push enabled, and APNs credentials for the application.

## Connect Apple Push Notification service

1. In Dokaai, open your organization and go to **Integrations → Notification providers**.
2. Choose **Apple Push Notification service**. Enter an integration name and complete the fields shown in the provider form. The form reflects the current provider configuration; keep credentials private.
3. Complete the test and install flow shown for this provider. Where a test recipient is requested, use a destination you control.
4. Select the installed integration when configuring the push channel for your notification handler.

## Verify delivery

Test with a device token from the correct app and APNs environment; check notification permission on the device.

Trigger a test notification from Dokaai and compare its result with the provider-side activity. An accepted request may not mean the message has reached the recipient; check the final delivery status where available.

## Troubleshooting

Check the app identifier, APNs credentials, token freshness, and whether the token matches the APNs environment.

If the provider accepted the message but it does not appear, check the recipient destination and the notification handler’s channel configuration. Update the integration if credentials have changed, then test again.
