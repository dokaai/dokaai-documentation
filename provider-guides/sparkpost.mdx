## Before you begin

- You need access to a Dokaai organization that can manage notification providers.
- Prepare a SparkPost API key and a sending domain configured for your account.

## Connect SparkPost

1. In Dokaai, open your organization and go to **Integrations → Notification providers**.
2. Choose **SparkPost**. Enter an integration name and complete the fields shown in the provider form. The form reflects the current provider configuration; keep credentials private.
3. Complete the test and install flow shown for this provider. Where a test recipient is requested, use a destination you control.
4. Select the installed integration when configuring the email channel for your notification handler.

## Verify delivery

Use a From address on the sending domain and inspect SparkPost message events.

Trigger a test notification from Dokaai and compare its result with the provider-side activity. An accepted request may not mean the message has reached the recipient; check the final delivery status where available.

## Troubleshooting

Review API key permissions, sending-domain status, suppression entries, and SparkPost events.

If the provider accepted the message but it does not appear, check the recipient destination and the notification handler’s channel configuration. Update the integration if credentials have changed, then test again.
